# GISDB v0.4.4

Author: Daniel Hallman

Published October 28, 2026.

This update makes the county-record, saved-search, and purchase instructions easier to follow. Descriptions explain source dates, missing records, account-inbox downloads, and the difference between pausing updates and cancelling billing. Short listing summaries now use complete phrases.

Update your installed package to receive the revised instructions. Existing connection URLs, tool names, account permissions, and service behavior are unchanged.

Follow the [GISDB setup guide](https://gisdb.io/integrations/0.4.1) to connect an assistant. The included OpenAI review draft still needs a verified recording and provider checks before submission.
